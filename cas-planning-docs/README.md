# CAS Planning Docs

Design documents for the Cooperative AI System (CAS) concept — a governance-first AI
workflow for cooperative environments that checks requests against defined policy before
responding, instead of an unconstrained model making judgment calls on its own. Governed
by the [Variables of Prompting (VoP)](../vop) framework.
