# Legal Notice & Mediation Batch Processing System (VBA version)

One-click document generation for demand letters and mediation forms, later
reverse-engineered from this undocumented VBA logic into a modern Python/PySide6
desktop application (see `WORKFLOW PORFOLIO/Legal Notice System/legal_notice_system_v5`
in this repo for that rebuilt version, which uses synthetic test data).

The original VBA workbook is not included here, as it contains confidential
legal/collection case data.
