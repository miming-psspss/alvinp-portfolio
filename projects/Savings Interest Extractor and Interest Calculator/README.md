# Savings Interest Extractor and Interest Calculator

Automates quarterly interest calculation across 7,000+ SAMCO savings accounts —
extracting balances from per-account Excel sheets and computing compounded interest.

**Note:** shipped as code only. The original sample data contained real account
numbers and real balances, so it's excluded pending a synthetic replacement dataset.

- `interest_extractor.py` — pulls balance data from per-account source sheets
- `data_extraction.py` — extraction/consolidation logic
