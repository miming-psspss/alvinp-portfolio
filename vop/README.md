# Variables of Prompting (VoP)

My personal framework for structured, disciplined AI-assisted development, built from
real prompt-drift failures and progressively formalized into a reusable spec.

| File | What it is |
|---|---|
| [`Variables_of_Prompting_Formal.docx`](./Variables_of_Prompting_Formal.docx) | The formal spec — the current, cleaned-up version of the framework |
| [`VoPV1.docx`](./VoPV1.docx) | Original v1 draft, kept for reference on how the framework evolved |
| [`VoP_Risk_and_Responsible_Use.docx`](./VoP_Risk_and_Responsible_Use.docx) | Risk and responsible-use notes — where the framework can go wrong and how to guard against it |
| [`VoP_Template.txt`](./VoP_Template.txt) | A working template for applying VoP directly in a prompt/session |

VoP is the governance backbone behind the [CAS project](../cas-planning-docs) — see the
[top-level README](../README.md) for how the two fit together.
